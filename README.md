# 报价自动填写助手

一个 Chrome / Edge 浏览器扩展：在报价/登记类网站上自动识别需要填写的项目，用你**保存在本机**的资料库一键填好，并能不断学习新项目。

## 隐私与安全（第一原则）

- **信息只保存在你自己电脑的浏览器里，绝不上传任何服务器。**
- 扩展**没有任何联网权限**，平时也不会读取你浏览的网页。
- 只有你主动点开插件、点按钮时，它才会在当前这一个页面上运行一次（扫描要填的框、填入你的资料）。
- 源码完全公开，欢迎核对：没有任何收集或上传信息的代码。

## 安装（首次，约 1 分钟）

1. 在本页右侧 **Releases** 下载最新的 `报价自动填写助手.zip`，解压到一个固定位置（如桌面）。装好后不要移动或删除该文件夹。
2. 打开 Chrome（Edge 步骤相同）。
3. 地址栏输入并回车：`chrome://extensions`（Edge 为 `edge://extensions`）。
4. 打开右上角「开发者模式」开关。
5. 点左上角「加载已解压的扩展程序」，选中第 1 步解压出的文件夹。
6. 列表出现「报价自动填写助手」即安装成功。
7. 点浏览器右上角拼图图标，把它固定到工具栏。

## 使用

1. 打开报价网站，让表单显示出来。
2. 点插件图标，它会**自动扫描本页**并列出要填的项目：
   - 绿色「已匹配」：已用你的资料自动填好（可改）
   - 橙色「新项目」：资料库还没有，可当场填并勾「学习」，下次自动认识
   - 灰色「库中无值」：认识该项目但你还没填内容
3. 核对后点「填入网页」，再回到网页核对并提交。

详见扩展内的《使用说明.txt》。

## 更新

本扩展通过「加载已解压」方式安装，不会自动更新。更新方法：

1. 到 Releases 下载最新 zip，解压覆盖原文件夹（或替换文件）。
2. 到 `chrome://extensions`，在本扩展卡片上点刷新按钮。
3. 已保存的资料库数据不会丢失。

## 技术说明

- Manifest V3；权限仅 `storage`（本地存储）、`activeTab` + `scripting`（点击时在当前页运行一次）。
- 无 `host_permissions`、无常驻脚本、无网络请求。
