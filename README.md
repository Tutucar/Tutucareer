# 报价自动填写助手

一个 Chrome / Edge 浏览器扩展：在报价/登记类网站上自动识别需要填写的项目，用你**保存在本机**的资料库一键填好，并能不断学习新项目；可选开启 **AI 智能匹配**，认出叫法刁钻、规则认不出的字段。

## 两种匹配方式

1. **规则匹配（默认，纯本地、不联网）**：按预设/你维护的「识别词」匹配网页字段，命中即自动填好。
2. **AI 智能匹配（可选，需开启并配置模型）**：当规则认不出某字段时，把该字段的**名称**和你资料库里的**类别名**交给大模型做语义归类，认出“贵司全称”“受托方名称”这类规则覆盖不到的叫法。被 AI 认出的项目会标注「AI 识别」徽标，提示你重点核对。

## 隐私与安全（第一原则）

- **你的资料内容（姓名/证件号/账号等）只保存在本机浏览器，绝不上传任何服务器。**
- **不开 AI 时**：扩展没有任何联网行为，只有你主动点开插件、点按钮时，才在当前这一个页面上运行一次（扫描要填的框、填入你的资料）。
- **开启 AI 时**：需要联网调用你指定的模型服务，但发送给模型的**只有两样**——网页字段的**名称**、你资料库的**类别名**；**绝不包含任何具体内容值**。填值永远在本机完成。
- 模型地址与密钥只存本机、只发往你自己配置的服务；联网权限按需申请，可随时在设置里关闭 AI 回到纯本地模式。
- 源码完全公开，欢迎核对。

## 安装（首次，约 1 分钟）

1. 在本页右侧 **Releases** 下载最新的 `报价自动填写助手.zip`，解压到一个固定位置（如桌面）。装好后不要移动或删除该文件夹。
2. 打开 Chrome（Edge 步骤相同）。
3. 地址栏输入并回车：`chrome://extensions`（Edge 为 `edge://extensions`）。
4. 打开右上角「开发者模式」开关。
5. 点左上角「加载已解压的扩展程序」，选中第 1 步解压出的文件夹。
6. 列表出现「报价自动填写助手」即安装成功。
7. 点浏览器右上角拼图图标，把它固定到工具栏。

## 使用

1. 打开报价网站，让表单显示出来。
2. 点插件图标，它会**自动扫描本页**并列出要填的项目：
   - 绿色「已匹配」：已用你的资料自动填好（可改）
   - 橙色「新项目」：资料库还没有，可当场填并勾「学习」，下次自动认识
   - 灰色「库中无值」：认识该项目但你还没填内容
3. 核对后点「填入网页」，再回到网页核对并提交。

详见扩展内的《使用说明.txt》。

## 更新

本扩展通过「加载已解压」方式安装，不会自动更新。更新方法：

1. 到 Releases 下载最新 zip，解压覆盖原文件夹（或替换文件）。
2. 到 `chrome://extensions`，在本扩展卡片上点刷新按钮。
3. 已保存的资料库数据不会丢失。

## 开启 AI 智能匹配（可选）

1. 点插件图标 →「管理」，拉到底部「AI 智能匹配」。
2. 勾选「启用」，选择接口协议，填服务地址、模型 ID、密钥：
   - 京东内部网关：JoyBuilder `https://modelservice.jdcloud.com/v1`、Oxygen `http://llm-gw.jd.local/v1`（选「OpenAI 兼容」）。
   - 其他 OpenAI 兼容服务（DeepSeek 等）同样选「OpenAI 兼容」。
   - Claude 原生/兼容选「Anthropic Messages」；本机 Ollama 选「Ollama」（无需密钥）。
3. 点「保存设置」，再点「测试连接」确认可用。
4. 之后扫描网页时，规则认不出的字段会自动交给 AI 补一轮。

## 技术说明

- Manifest V3；基础权限仅 `storage`（本地存储）、`activeTab` + `scripting`（点击时在当前页运行一次）。
- 联网权限 `http/https` 为 **optional（按需申请）**：仅在你开启 AI 并保存时才请求；不开 AI 则扩展零联网。
- AI 调用在扩展内直接请求你配置的模型服务，只发字段名/类别名，不发资料内容值。
